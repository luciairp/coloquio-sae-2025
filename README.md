# Pingüinos
Variables ambientales: SST, Chla, SSTA, SAM
¿Con qué distribución se puede modelar la razón pichones/huevos por nido? ¿Cómo se evaluará la componente espacial (estaca)? 
Opciones para la variable respuesta: multinomial con resultados posibles 0, 1, 2 (filtrando los nidos que comenzaron con 1 o 3 huevos = 34 datos menos); o como razón tomando la cantidad real de huevos al inicio en cada nido.

# Arroyos
Se asume constante la presión de  la columna de aire para todos los arroyos, por lo tanto las diferencias van a estar dadas por el agua (aunque no sepamos cuánta agua es).
